Robots, drones and a charger on a simulated mountain.

A multi-agent simulation built in Mesa, run three ways: random exploration, drones messaging robots, and a graph neural network choosing actions. Across the recorded runs, the rule-based Extended mode rescues about 2.5 times as many people as the GNN-MARL Novel mode.

These are recorded runs, not a live simulation. Each one was run with the project's real Mesa code on a local machine, every agent position was saved at every step, and your browser only plays the file back.

    Against the project's KPI report of 16 July 2025, Extended reproduces run for run, including message counts. Novel's mean agrees, but its individual runs differ: the notebook did not seed PyTorch, so its learning runs are not repeatable.

    Novel is exploring

    The checkpoint loads weights (50 episodes, 25,000 training steps) but not the exploration rate, so each run restarts at epsilon 0.9 and only falls to 0.554 by the end. These runs show the mode as the project ran it, not a greedy evaluation of the policy.

    Novel's clock differs

    In Novel mode the model's step counter advances twice per tick (1,000 by the end) and the spawner runs twice. Its map reaches the 30-person cap by about tick 105 to 150, against 240 to 300 in Extended, so Novel faces more people earlier.

    Where the code came from

    The recordings use the author's working copy. The public repo does not yet include src/gnn_marl.py or the checkpoint, so Novel cannot be re-run from GitHub alone. The recorder is in demo/tools/.

    Rescue rate per training episode

    From results/training_metrics.json. Tab to the chart and use the arrow keys to read values.

    No upward trend over 250 episodes. Mean rescue rate is 5.8% in the first 50 episodes and 5.7% in the last 50. The best episode, 46.7%, came early, and all five periodic evaluations are recorded as 0.0.

    Curriculum learning stayed on the easiest stage. results_curriculum/ holds 101 episodes on an 8×8 map with 2 robots and 1 drone. The mean rescue rate was 46.2% over the last 30 episodes. It moved up a stage at episode 100, fell back at episode 101, and completed no stages. Both of its evaluations are recorded as 0.0.

    So the GNN-MARL system runs end to end with dynamic graphs, but these saved results do not show it outperforming the rule-based coordination it was meant to improve on.
